## 1. 产品定位与差异化（v2.0 新增）

### 1.1 一句话定位

**「30 秒，把任何脑洞变成能火的动画短视频」——AI 动画界的抖音。**

### 1.2 与 OiiOii 的差异化（技术对齐 · 心智不同）

| 维度 | OiiOii | 绘梦工坊 |
|---|---|---|
| 产品定位 | 专业 AI 动画工作台 | AI 动画社交创作平台（创作即消费） |
| 目标用户 | 半专业创作者 / 广告主 | 泛大众 + UGC 创作者 + B 端商家 |
| 上手成本 | 需理解 7 智能体概念 | 模板一键 30s / 三步向导 3min，零门槛 |
| 内容生态 | 纯工具，无社区 | 作品广场 + 合拍 + 挑战赛 + 模板署名裂变 |
| 获客方式 | 评测口碑 + waitlist 饥饿营销 | 开放即用 + 社交裂变 + 承接等待人群 |
| 收入模式 | 高端订阅 | 免费 + 会员 + 企业 API 三层 |
| 内容调性 | 专业电影感 | 短视频原生（9:16、快节奏、配乐卡点、自动字幕） |

### 1.3 三大 USP（最大卖点）

1. **极简**：30 秒出片（对 OiiOii 零学习成本）
2. **能火**：短视频原生设计 + 爆款模板库（作品天生适合传播）
3. **会裂变**：合拍二创 + 模板复用署名 + 挑战赛（用户即渠道）

### 1.4 用户画像（Persona）

| Persona | 画像 | 核心诉求 | 付费意愿 |
|---|---|---|---|
| 短视频爱好者（小美，23 岁） | 刷抖音/小红书，想发有趣内容但不会动画 | 快速出片、模板多、好看能涨粉 | 中（冲动付费） |
| 中小商家（王老板，35 岁） | 电商/餐饮店主，需要商品宣传动画 | 商品动画化、批量生成、价格敏感 | 高（工具付费） |
| 学生创作者（阿凯，19 岁） | 动画/设计专业，有创作欲 | 自由创作、专业风格、作品被认可 | 低（免费为主） |

## 2. 目标与北极星指标（v2.0 新增）

### 2.1 北极星指标

**周活跃创作人数（WAU-创作者）**：每周完成 ≥1 次生成的去重用户数。

### 2.2 AARRR 指标

| 阶段 | 指标 | 目标（上线 3 个月） |
|---|---|---|
| 获取 | 注册转化率、邀请裂变系数 K | 注册转化 ≥15%；K ≥ 0.3 |
| 激活 | 首次出片率（30s 内）、向导完成率 | ≥60% |
| 留存 | 次周留存、连续创作 ≥3 天占比 | 次周留存 ≥25% |
| 收入 | 免费→付费转化率、ARPU | 转化率 ≥5%；ARPU ≥¥12/月 |
| 传播 | 分享率、合拍率 | 分享率 ≥10% |

### 2.3 创作目标（体验基准）

- 新用户首次出片 ≤ 30 秒（模板路径）或 ≤ 3 分钟（向导路径）
- 生成成功率 ≥ 95%（排除内容违规拦截后）

## 5. 核心流程：双创作路径（v2.0 重构）

```text
路径 A（30 秒·新手）：
[首页/模板库] → 选一个爆款模板 → 替换主角/文案（可选）→ 一键生成 → 出片分享
路径 B（3 分钟·进阶）：
[创作向导] → 步骤1 输入创意（对话补全）→ 步骤2 选风格 → 步骤3 生成 → 智能画布精修 → 出片
两条路径汇合：结果页 → 智能画布 → 导出/发布/合拍
```

- 路径 A 是**激活钩子**（新手先爽一次），路径 B 是**留存深度**（进阶创作）
- 草稿自动保存（localStorage + 服务端），任意位置可退出恢复

## 7. 任务状态机与并发（同 v1.0，保持不变）

```text
DRAFT → QUEUED → RUNNING → SUCCESS
                ↘ FAILED → 重试(≤3) → QUEUED
      RUNNING → CANCELLED（额度返还）
```
- generate 带 Idempotency-Key；同一 creation 同时仅 1 个 RUNNING 任务
- 渲染阶段不可取消（返回 409 并说明）

## 8. 转化与增长机制（v2.0 新增专章）

### 8.1 心流断点收费（原则）

付费墙只出现在两个情绪高点，绝不在创作中途打断：
1. **出片瞬间**：预览完想导出无水印 → 弹出会员引导（可关闭，30s 后弱化为横幅）
2. **额度用尽**：点击"继续生成" → 展示本月创作成就 + 升级引导

### 8.2 裂变设计

| 机制 | 设计 |
|---|---|
| 品牌水印 | 免费导出带"绘梦工坊"角标水印（位置不遮挡主体） |
| 分享海报 | 生成二维码海报（作品封面 + 标题 + 二维码），保存/分享 |
| 模板署名 | 合拍作品展示"基于 @作者 的模板" |
| 邀请奖励 | 邀请好友注册，双方各 +2 次生成额度 |

### 8.3 运营冷启动（P0 配套）

1. 50 个官方爆款模板（首发即饱和）
2. 每日挑战赛（上线第 1 天就开始，制造话题）
3. 3 个 KOL 种子创作者（预置账号，贡献高质量作品）
4. 每周模板上新（运营节奏固定化）

## 14. 异常与降级

| 场景 | 处理 |
|---|---|
| 生成失败 | 定位阶段 → 重试(3) → 人工工单；额度返还 |
| 模型不可用 | 多引擎自动切换；无备用返回 503 + 提示 |
| 排队过长 | >5min 提示会员优先队列 |
| SSE 断开 | 前端降级 3s 轮询 |
| 审核未通过 | 作品不公开，仅自己可见 + 修改引导（不泄露敏感词） |
| 支付失败 | 订单状态机重试 + 客服入口 |

# 附录 A：视频局部修改技术评估（v2.0 附录）

> 本附录回答一个决定"智能画布"真实性的关键问题：**生成的视频中做部分修改，能否实现？难度多大？**
> 结论：**能做，但必须区分 6 种技术难度完全不同的"修改"**。产品承诺范围 = 轨道级 + 镜头级（技术可控，覆盖 90% 用户诉求）；像素级重绘放 P1 实验；运动修改明确不做。

## A.1 六种修改类型与难度矩阵

| # | 用户诉求 | 技术本质 | 难度 | AI 成本 | 业界现状 | P0 承诺 |
|---|---|---|---|---|---|---|
| 1 | 改字幕/标题 | 重渲染文本轨 → 合成 | ★ | 0 | 成熟 | ✅ 承诺 |
| 2 | 换配乐/配音 | 替换音轨 + 混流 | ★ | 低 | 成熟 | ✅ 承诺 |
| 3 | 改画幅/裁剪/删段 | FFmpeg 剪辑/转码 | ★ | 0 | 成熟 | ✅ 承诺 |
| 4 | 换角色外观/场景（整镜头） | 种子资产 + 新指令 → 重生成该镜头 | ★★☆ | 高（1 次生成） | 主流方案 | ✅ 承诺（镜头级） |
| 5 | 像素级局部重绘（只改一个区域） | 第三方视频编辑模型 API | ★★★★ | 高且不稳定 | 前沿，成功率 60-80% | ⚠️ P1 探索 |
| 6 | 改运动方式（走→跑） | 运动语义重写 | ★★★★★ | — | 研究级 | ❌ 不做 |

**关键认知**：用户感知是"局部修改"，技术实现是**"局部重生成 + 轨道重新合成"**。

## A.2 可编辑架构：分离式渲染（实现前提）

**原则**：视频不能当整体黑盒存，必须生成时拆三层落盘，修改时才"只动该动的地方"。

| 层 | 内容 | 修改能力 |
|---|---|---|
| 镜头层 | 每个镜头独立视频文件 | 镜头级重生成/删除/排序 |
| 轨道层 | 画面轨/字幕轨/配音轨/配乐轨/音效轨分离 | 轨道级修改（秒级，AI 成本≈0） |
| 种子资产 | 角色图/场景图/分镜脚本（一致性锚点） | 重生成镜头时锁定风格一致性 |

**修改流程**：
- 轨道级（A 路径）：只重渲染对应轨道 → FFmpeg 重新合成 → 秒级
- 镜头级（B 路径）：种子资产 + 新指令 → 重生成受影响镜头 → 重新合成 → 分钟级（1 次生成成本）
- 像素级（C 路径，P1）：第三方视频编辑模型 → 失败自动重试 → 成功率高才转正

**对主体的影响**：§6.3 智能画布、§12 assets/versions 表设计已与本架构对齐，无需推翻，只需在实现时**强制流水线分层落盘**。

## A.3 业界现状与风险（诚实说明）

| 事实 | 说明 |
|---|---|
| 像素级局部重绘 | 可灵/Runway/Pika 已开放局部编辑，但仅支持数秒片段、成功率约 60-80%、需多次尝试、API 成本高 |
| 时序一致性 | 编辑区域在连续帧间仍可能闪烁/抖动——全球性难题 |
| 自研视频编辑模型 | 生产级需千万级投入 + 数月，不建议；正确路线是"接第三方 + 产品工程包装" |
| 我们的护城河 | 不是自研模型，而是**分离式渲染架构 + 一致性种子资产 + 版本管理**这层产品工程能力 |

## A.4 产品承诺边界（UI 预期管理）

1. **P0 承诺**：改字幕/标题、换配乐/配音、改画幅/删段（秒级）；换角色外观/换场景（镜头级，分钟级）
2. **P1 实验**：像素级局部重绘，标注"高级实验室功能"，失败自动重试
3. **明确不做**：运动方式修改（准备客服话术）
4. **UI 诚实性**：用户操作时明确提示"修改会重新生成受影响镜头"，避免误解为像素级编辑
